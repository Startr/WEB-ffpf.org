# ffpf.org restyle plan (2026-10-20)

Parked on 2026-10-25 while the dinner sponsor work runs; the drafts it describes are live at /drafts/. Board card: TODO.md, "The new look".

## In plain words (start here)
Think of the website as a house.

The foundation's site was built over the years by many hands. Each room is painted a slightly different red. Some rooms have their own wallpaper, and some lights are borrowed from the neighbours (other websites).

Our own apps, like Trellis, are built from one shared kit of parts: the same paint, the same doors, the same light switches. Tony has been designing how those rooms look and feel.

This plan does three things:
- **Repaints ffpf with our shared kit.** The FFPF red, the FFPF grey and the FFPF logo stay. Everything is one consistent red, the text is easier to read, and it works well on phones.
- **Borrows Tony's finishing touches:**
  - a soft red glow behind each page title, with a faint icon;
  - a frosted-glass top bar;
  - gentle motion that switches off for people who prefer less movement;
  - pages that slide smoothly from one to the next (Startr Swap) instead of blinking white.
- **Stops borrowing from neighbours.** The site's style, letters and icons are served from ffpf itself, so it is faster and more private for visitors.

Nothing changes on the real site until it has been shown and approved. First come **mockups**: picture-perfect sample pages, made by Sage.is AI and polished by Tony. Alexander picks the look. Then we build it on a private test copy of the site. Dr. D or Vinod look at that copy and sign once for "the new look". Only after that does it go live.

## Context
ffpf.org loads startr.style but fights it. It has 8 `<style>` blocks and about 50 site classes (`.cell`, `.line`, `.image-dir`, `.title-overlay`, the gala and modal classes). It has 37 headings in literal `red` and grey cards with white text at 1.9–2.8:1 contrast. It sets "Abel" without ever loading it, and its 12px size override has no effect. It loads WOW.js, animate.css and Font Awesome from CDNs, and the kit itself from the rolling `https://startr.style/style.css`.

Trellis styles only with kit tokens and inline props. It has no classes, no `<style>` blocks, self-hosted Nunito Sans, a copy of the kit kept in the repo, and a `make kit_check` gate.

Alexander wants ffpf in that idiom without losing FFPF's identity: the logo red `#ed1d24`, the logo grey `#6d6f71`, and the two logo images. Dr. D or Vinod sign off on the result as one item: "the new look".

The look also takes in Tony's style work. Tony is Anatoli Chastik (`AnatoliHS`). He wrote the Trellis design drafts in `WEB-AI-Sage-Trellis/crm/docs/design-drafts/`, latest 2026-10-18 on `feature/frontend-ux`. Their direction was approved on 2026-10-16 (`HANDOFF.md`, "Answers so far"):
- kit tokens and startr.style 1.x states (`--bg-hover`, `--oe-focus`, `--bg-on`);
- `--anim` with `st-fade`, `st-rise`, `st-slide-in`, `st-pop` and a reduced-motion guard;
- `--text-grad`, `--glow`, `--bdf`, and `--tone`/`--mix` tints.

ffpf carries over three of his elements: the header wash with a watermark, glass and glow, and the motion set. His Notch dock is left out because ffpf is a public site, not an app. **Mockups come first**; nothing is built until Alexander picks.

## Phase 2 [WE]: theme sheet and page shell
`src/assets/theme/ffpf.css` is the one sanctioned sheet. It holds tokens plus two kit-gap rules:
```css
:root {
  --primary: #ed1d24;              /* logo red: bars, borders, icons, focus (4.37:1, never body text) */
  --secondary: #6d6f71;            /* logo grey, 5.05:1 on white */
  --primary-deep: var(--primary);  /* fallback without color-mix */
  --button-hover: var(--primary);
  --text-muted: var(--secondary);  /* kit default is 2.38:1 */
  --links: var(--primary-deep);
  --element-bg: var(--primary-deep); /* the kit's button fill hook */
}
:root, [data-theme] { --primary-tint: var(--bad-bg); }
@supports (color: color-mix(in oklch, red 10%, white)) {
  :root { --primary-deep: color-mix(in srgb, var(--primary) 80%, black);   /* ≈#be171d, white on it 6.31:1 */
          --button-hover: color-mix(in srgb, var(--primary) 66%, black); } /* 8.33:1 */
  :root, [data-theme] { --primary-tint: color-mix(in oklch, var(--primary) 8%, var(--background)); }
}
/* Kit gaps. Upstream fixes are proposals for Alexander; no edits to Startr/Style. */
[hidden] { display: none !important; }      /* kit display rules beat [hidden] */
[data-submenu] > ul { display: none; }      /* no parent :focus-within state in the kit */
[data-submenu]:is(:hover, :focus-within) > ul { display: block; }
```
- The tokens move to `:root`. Today `--primary` sits on `<body>`, so `--links` and the tint still derive from the kit's purple.
- `base.njk`:
  - Body: drop `--primary`, `--links`, `--typo-size-6`, `font-size`, the stray `0` and `--maxw-md`.
  - Footer: `--bg:var(--primary-deep)`.
  - Hero: move the gradient onto the figcaption (the current `--grad` paints behind the image); use `--radius`.
- `head.html`: delete the nav `<style>` (lines ~49–79) and the smooth-scroll script, which cancels the skip link's focus.
- `nav_en.html`:
  - `data-submenu` on the three parents; drop `--translatey-hvr`.
  - Link states use `-hover`, `-focus` and `-on`, with `aria-current` set at build time.
  - Donate becomes a `pill` and Volunteer a `pillOutline`; drop `class="button"` and `class="home-link"`.
- `post.njk`: the `links-nextprev` class becomes props.

## Phase 4 [WE]: one idiom per component

| Idiom | Use |
|---|---|
| `pill` / `pillOutline` | Donate, Volunteer, every CTA, and the `<a><button>` pairs |
| `card` | The whole link is the card; tint on hover and on, focus ring |
| `panel` | Board headshots: white, `--shadow:6`, `--radius:.6rem`, round photo with a white ring |
| `label` | Replaces the `--c:gray` and `#666` subtitles |
| `notice` | Mission timeline entries (red left rule on the tint) |
| `title` | Page titles (`--size:1.6rem; --size-md:2rem`) |
| `grid` | `minmax(min(100%,15rem),1fr)`, replacing `minmax(500px)` |
| `prose` | 42rem column for articles, set through a directory data file in `src/article/` and `src/fr/article/` |
| `lineHeading()` | The red side-line heading, with real `<span aria-hidden>` bars instead of `::before`/`::after` |
| `icon()` | Inline SVG icons |
| `caption()` | A 60% black bar so white text on any photo reaches ≥5.74:1; replaces `.title-overlay` |

  - `data-swap-off` goes on links that must reload in full: `/donate` (it leaves for CanadaHelps), links to the French WordPress-layout pages and `/fr/feed` (different chrome), `/admin/`, and feeds.
- **Inline scripts never run after a swap.** Move the gala popup (`src/index.html`), the `/2026/` carousel (`year.md`) and the Team Canada countdown into behaviour scripts in `src/assets/js/`, loaded once in the layout.
  - Each starts on `DOMContentLoaded` and again on `swap:after`.
  - Each start is idempotent, marked by a `data-ready` attribute.
  - Scripts toggle `hidden`, `aria-*` or `data-on` only, never classes.
- **Shell after a swap:**
  - Update `aria-current` on nav links on `swap:after`.
  - Close any open submenu.
  - Move focus to the new `<main>` heading.
  - Matomo: `_paq.push(['setCustomUrl', location.href], ['setDocumentTitle', document.title], ['trackPageView'])` on `swap:after`, so swapped views are counted.
- **JavaScript off:** every link stays a normal link.

## In plain words (the wrap-up)
When this is done, ffpf.org looks like a sister of our own apps and is unmistakably FFPF: the same red, the same logo, the same voice.

**Visitors get:**
- text that is easy to read;
- buttons that are easy to tap on a phone;
